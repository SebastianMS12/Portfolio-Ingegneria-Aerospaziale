# Analisi Strutturale FEM di un Cassone Alare (MSC Patran/Nastran & MATLAB)

Modellazione agli elementi finiti (SOL 101) di un cassone alare a sezione quadrata sottoposto a taglio e flessione, con post-processing in MATLAB dei report numerici (`.rpt`) e confronto con la soluzione analitica della trave a semiguscio.
