# Analisi Aerodinamica e Stabilità di un Velivolo (OpenVSP/VSPAERO & Python)

Modellazione parametrica 3D di un velivolo con impennaggio a V e simulazione aerodinamica VLM subsonica ($M = 0.5$) tramite VSPAERO. Estrazione automatizzata in Python (Pandas, Matplotlib) delle polari ($C_L, C_{Di}$) e delle derivate di stabilità (`.stab`) per il calcolo del margine statico longitudinale ($K_n$).
